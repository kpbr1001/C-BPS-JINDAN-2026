AI 진단

심사위원이 감점하는 지점을 제출 전에 먼저 봅니다. 지원공고·작성양식·사업계획서를 비교해 자격 적합성, 감점 리스크, 보완 방향을 심사위원 관점으로 진단합니다.

🎯

공고 적합성 진단

지원대상·신청자격·제외요건을 공고문 기준으로 비교해 신청 가능 여부를 점검합니다.

📊

평가항목 대응도 분석

공고에 명시된 평가항목·배점이 있을 때 항목별 반영 수준과 감점 가능성을 진단합니다.

🧭

심사위원 관점 보완 가이드

문항별 강점·약점과 수정 우선순위, 필요한 증빙자료를 제시합니다.

STEP 1

문서 업로드

지원공고문과 사업계획서는 필수, 작성양식·참고자료는 선택입니다. PDF, DOCX, HWP 변환 파일, TXT를 지원합니다.

STEP 2

기업정보 입력 (선택)

입력하지 않은 항목은 진단에서 “미입력”으로 표시되며, 임의로 채우지 않습니다.

이용 전 유의사항
· 개인정보·영업비밀이 포함된 문서 업로드 시 주의하시기 바랍니다. 입력값은 브라우저 내에서만 임시 보관됩니다.
· 본 도구는 참고용 진단이며, 선정·평가 결과를 보장하지 않습니다. 최종 판단은 주관기관 공고문과 심사위원 검토에 따릅니다.
· AI가 생성한 분석이므로 오류나 부정확한 내용이 포함될 수 있습니다. 제출 전 반드시 응답 내용을 직접 확인하시기 바랍니다.
· 현재는 MVP 단계로, AI 분석 API 연동 시 업로드 문서 기반의 실제 진단 결과가 표시됩니다.

6강점과 약점 진단

예시 데이터

💪 이대로 살릴 강점

  • 진단 실행 후 강점이 표시됩니다.

⚠️ 지금 채워야 할 약점

  • 진단 실행 후 보완할 약점이 표시됩니다.
💡
핵심 진단: 강점은 "이미 가진 것(문제의식·차별성)"이고, 약점은 대부분 "있는데 안 쓴 것(근거·증빙·숫자)"입니다. 즉 새 역량을 만드는 게 아니라, 보유한 내용을 근거의 언어로 바꾸는 작업이라 짧은 기간에 점수를 끌어올릴 수 있습니다.
🔗 강점으로 약점 방어하기 — 가진 것을 무기로
ℹ️
이미 확보한 강점을 관련 약점의 근거로 활용하는 연결 제안입니다. 심사위원에게 "이 팀은 이미 증명했다"는 신호를 주는 서술 전략입니다.

7지원공고 적합성 진단

입력 기반 점검

입력하신 기업정보를 일반 정부지원사업 자격 기준으로 해석해 충족 가능성을 판정합니다. 초록은 충족 가능, 노랑은 공고 대조 필수, 빨강은 자격 제한 우려입니다. 최종 자격은 반드시 공고문 원문으로 확인하세요.

점검 항목입력값자격 판정상태조치 사항
📌 본 판정은 일반적인 정부지원사업 자격 기준으로 입력값을 해석한 참고용 사전진단입니다. 실제 자격·제외 요건은 업로드한 공고문 원문과 세부 운영지침을 따르며, 최종 신청 가능 여부는 주관기관 판단에 따릅니다.
🚦
가장 먼저 할 일: 자격요건은 점수가 아니라 신청 가능 여부 자체를 좌우합니다. '확인 필요'·'미확인' 항목을 공고문 원문과 대조해 신청 자격부터 확인하세요.

✎근거 없는 핵심 주장 진단

AI 분석 결과

감점 리스크(8번)가 "무엇이 빠졌나"를 본다면, 여기서는 "쓰긴 썼는데 근거가 없는 단정"을 봅니다. 시장규모·매출·경쟁력을 출처·수치 없이 사실처럼 진술해, 심사위원이 "근거는?"이라고 되물을 문장만 짚습니다.

✎
왜 중요한가? 심사위원은 핵심 주장에 근거가 없으면 감점합니다. 특히 시장규모·매출·경쟁력·실현가능성 같은 당락 요소는 반드시 출처·수치로 뒷받침해야 합니다. 아래 문장을 개선 예시처럼 근거 기반으로 바꾸면 감점을 막을 수 있습니다.

8감점 리스크 & 실행 로드맵

예시 데이터

심사위원이 감점할 지점과, 각각을 어떻게 막을지 — 진단부터 실행 단계·소요기간까지 한 카드에 정리했습니다. 위에서부터 우선순위입니다.

📉
리스크 합산: 점수형 리스크를 방치하면 종합점수가 하락해 선정 경쟁력이 약화됩니다. 보완 시 점수 회복이 가능한 구조입니다. 자격요건은 점수와 별개로 신청 가능 여부를 결정하므로 최우선 확인 대상입니다.
